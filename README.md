# 动作闯关游戏 - Action Game

## 项目简介

使用STM32F103VE（以下简称开发板），连接笔记本，结合使用MediaPipe Pose模型，对以下项目生成项目框架，并初步完成项目内容。同时，将项目具体内容分给五个人的工作量指示每个人可以完成哪一部分内容，如何进行联合调试：
总体而言，这是一个“动作闯关”游戏，使用开发板的摄像头功能，完成类似“识别人体动作”，并与随机生成的目标人体动作匹配。玩家在摄像头前完成动作，如果与目标动作匹配则得分，得分达到阈值挑战成功。
1. 在网页端有精美的页面设计，对于不同用户解锁不同的游戏进度。在某一关游戏开始后，依次进行多个动作闯关。每个目标动作在网站上显示目标人体动作模型，并在倒计时结束后显示摄像头拍摄到的照片所提取出的人体模型，当差别不大时当前动作完成，并成功计分。每一关的合计动作成功数量就是这一关的得分。
2. 使用开发板的摄像头，摄像头链接在开发板上。在网页上的倒计时结束后拍摄照片，并传输给电脑端处理照片。
3. 在电脑端进行主要程序处理，与网站和开发板进行信息传输。接受到照片后使用MediaPipe Pose模型对动作进行识别，如果与生成的动作类似就判定动作一致，并将信息进行传递。同时进行游戏数据管理。

## 关于此项目

建议安装 git for windows 在 windows 系统上使用 git。

### 1. 如何编辑此项目

```bash
git clone https://github.com/EricQian06/action-game.git
cd action-game
```

这样就完成了本项目的本地克隆。

```bash
在每次开始编辑之前，运行以下命令与仓库保持同步：
git pull
在完成编辑后运行以下命令上传代码：
git add -A
git commit -m "留言"
git push -u origin master
```

### 2. 如何运行此项目

在 `server/detect` 中的 `test.mp4` 是一段深蹲视频，运行以下命令完成深蹲计数：

```bash
python squat_detector.py --mode video --video_path ./test.mp4 --output ./output.mp4
```

使用以下命令进行实时摄像头拍摄并进行深蹲计数：

```bash
python3 squat_detector.py --mode realtime --camera 0
```

安装 python 依赖

```bash
cd server
pip install -r requirements.txt
```

初始化数据库

```bash
cd tools
python setup_db.py
```

启动服务器

```bash
cd server
python app.py
```

服务器将在 `http://localhost:5000` 启动

启动前端

直接使用浏览器打开 `web/index.html` 或使用Live Server:

```bash
cd web
live-server --port=3000
```

连接硬件

1. 将STM32开发板通过USB连接到电脑
2. 确认串口号(COM3或类似)
3. 在配置文件中修改串口设置
4. 复位STM32开发板

## 技术栈

### 硬件层

- **MCU**: STM32F103VE (ARM Cortex-M3)
- **摄像头**: OV7670 / OV7725
- **通信**: USB转串口 (115200/921600 bps)

### 上位机层
- **语言**: Python 3.8+
- **Web框架**: Flask 2.3.3
- **实时通信**: Flask-SocketIO 5.3.6
- **串口通信**: PySerial 3.5

### 算法层
- **姿势检测**: MediaPipe Pose 0.10.8
- **图像处理**: OpenCV 4.8.1
- **数学计算**: NumPy 1.24.3

### 展示层
- **前端**: HTML5 + CSS3 + JavaScript (ES6+)
- **实时通信**: Socket.IO Client 4.5.4
- **UI组件**: 原生组件 + 自定义样式
